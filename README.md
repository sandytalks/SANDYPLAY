## ✦ Hardware & playback engine

-   **LibVLC playback:** 4K/8K hardware decoding support using available
    GPU acceleration paths such as NVDEC, QuickSync and DXVA2.
-   **RTL-SDR FM tuner:** With a compatible RTL2832U dongle, tune
    76--108 MHz FM broadcasts.
-   **Parallel Stream Proxy:** Internal multi-threaded HTTP proxy on
    port `8125` for segmented online media delivery.
-   **HDR controls:** Adjust contrast, brightness, saturation, gamma and
    hue with presets.
-   **Media downloader:** Multi-threaded chunk downloading with FFmpeg
    remuxing support.

### Installation steps

1.  Download `SandyPlay_Setup_v1.18.exe` using the release link above.
2.  Run the installer on a supported 64-bit Windows system.
3.  Follow the setup wizard.
4.  Launch SANDYPLAY from the desktop or Start menu.

The project describes the installer as bundling the LibVLC engine, OliX
Audio core, Faster-Whisper runtimes, codecs and Visual C++ dependencies.
